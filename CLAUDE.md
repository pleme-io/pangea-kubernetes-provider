# pangea-kubernetes-provider

Auto-generated typed Kubernetes Terraform resource functions for the Pangea IaC DSL.
All resource code is generated by `terraform-schema-importer` from the
HashiCorp Kubernetes Terraform provider schema.

**Note:** This is distinct from `pangea-kubernetes` which provides hand-written
cloud-agnostic Kubernetes cluster abstractions. This gem wraps the Terraform
`kubernetes` provider for managing in-cluster resources (pods, services,
deployments, etc.).

## Generation

```bash
terraform-schema-importer generate \
  --schema schema.json \
  --provider "registry.terraform.io/hashicorp/kubernetes" \
  --provider-name kubernetes \
  --output-dir .
```

## Resources: 82

All resources use the `define_resource` DSL with `Dry::Struct` type validation.
Module: `Pangea::Resources::Kubernetes`, prefix: `kubernetes_`.

## Regeneration

1. Update the provider version in a Terraform workspace
2. Run `terraform init && terraform providers schema -json > schema.json`
3. Run the generate command above
4. Run `bundle exec rspec` to validate
5. Commit the updated files

## Dependencies

pangea-core ~> 0.2, terraform-synthesizer ~> 0.0.28, dry-types ~> 1.7,
dry-struct ~> 1.6. Ruby >= 3.3.
